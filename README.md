Repositorio de trabajo del laboratorio de INF2310.

Cada directorio `semanaNN/` contiene el capstone de esa semana.

| Semana | Tema | Entregable |

| 04 | Búsqueda, archivado y entorno propio | `respaldar-trabajo.sh` |
| 05 | Bash: fundamentos | `info-sistema.sh` |
| 06 | Bash: condicionales | `validador.sh` |
| 07 | Bash: loops, arrays y funciones | `gestor-tareas.sh` |
| 08 | Procesos y señales | `monitor-procesos.sh` |

| 10 | El modelo de objetos | `analizar-datos.ps1` |
| 11 | Filtrado, selección y agregación | `consultas.ps1` |
| 12 | Archivos, providers y datos | `organizar-archivos.ps1` |
| 13 | Procesos y control de la salida | `monitor-procesos.ps1` |
| 14 | Scripting en PowerShell | `gestor-tareas.ps1` |
